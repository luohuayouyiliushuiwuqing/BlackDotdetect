# 远距离无人机黑色小目标检测模型设计方案

> ## ⚠️ 实现状态说明（2026-10-20）
> 本文档最初按“4 分类 + 20×20 输入 + 双头网络”编写，**当前代码已演进**。与正文冲突处，以本说明为准：
> 1. **任务改为二分类**：无人机/飞机 = 正类(1)，其余（天空边缘、云层边缘、背景）= 负类(0)。
> 2. **输入改为 36×36**：目标居中，外圈 8px 为背景环带，供局部背景估计（相对暗判定的基础）。
> 3. **网络改单头**：`DroneNet`（~7.6 万参数），输出单个 sigmoid 概率 `P(无人机)`，损失 `BinaryFocalLoss`。
> 4. **合成目标尺度 2×2~18×18**，并采用 **size-aware blur**（模糊强度随目标尺度缩放），保证极小目标可学。
> 5. **推荐纯 CNN**：消融表明训练充分后去掉手工特征分支更优（AUC 0.945 vs 0.928），部署预处理快 28×、端到端快 1.9×，且整网无 OpenCV 依赖可直接上 NPU。手工特征仅作可选先验（`--no-handcrafted` 关闭）。
> 6. 训练 / 验证 / 部署的完整流程见 **[训练与验证指南.md](训练与验证指南.md)**。
>
> ### 2026-10-21 修订（代码审查后同步）
> 7. **暗像素统计区修正**：阈值按 **中心 20×20 目标区**标定，因此 `core_region()` 只在目标区内统计暗像素，背景 μ/σ 仍由外圈 8px 环带估计。此前统计跑在整个 36×36 画布上，导致规则基线永久不触发（F1=0），修正后正样本"存在性"通过率 0% → **54.7%**。
> 8. **规则判据阈值重标定**：实测无人机 `sym` 中位 0.304、天空/云边缘 ≈ 0.000，故团状判据由 `sym≥0.4` 下调为 **`sym≥0.15`**；闭合对比度下限由 0.25 下调为 **0.12**（模糊退化后目标芯对比度实测约 0.1~0.4）。规则基线 AUC 0.576 → **0.708**。
> 9. **时延预算口径统一**：`benchmark_onnx.py` 原将 batch=30 的**批总耗时**与"每 ROI 2 ms"预算比较，误判不达标；已改为按 ROI 折算（实测 **0.252 ms/ROI**，达标）。
> 10. **基线评分逻辑修正**：传统算法的评分代理由"仅当判为团状时给分"改为"检出黑色元素即报警"，否则边缘误报被掩盖、P/R 恒为 0，失去对照意义。

## 1. 任务定义与问题分析

### 1.1 任务描述
> **已更新为二分类**（见文档顶部状态说明）。

在天空背景下，对 **36×36 像素**的 Y 分量（亮度）ROI 做**二分类判别**：该 ROI 中是否存在**无人机/飞机**这类黑色小目标（正类=1，其余=0）。

负类包含天空边缘、云层边缘、纯背景——它们是与无人机最易混淆的"暗边缘/暗区"，是负样本的主要来源，必须保证其数量与多样性。

### 1.2 难点分析（为什么传统算法失效）
- **信息极度稀疏**：20×20 区域内有效目标像素可能仅 5~50 个，传统形态学+阈值方法依赖的连通域形状特征几乎不可用。
- **三类目标在低分辨率下亮度分布高度重叠**：远距离无人机呈"暗色斑点"，而天空/云层边缘在高斯模糊和下采样后同样会产生局部暗像素带，纯阈值法无法区分"边缘过渡的暗"与"实体目标的暗"。
- **边缘与斑点的本质区别**：边缘暗像素呈**条带状、单侧渐变、沿边缘方向连续**；无人机目标呈**紧凑团状、四周均与亮背景形成闭合对比、各向梯度近似对称**。这一差异需要空间结构建模（CNN/手工结构特征），单像素阈值无法表达。

## 2. 模型输入输出定义

### 2.1 输入定义

| 项目 | 定义 |
|---|---|
| 主输入 | Y 分量 ROI 图像块，统一缩放/填充至 **36×36×1**（uint8 归一化到 [0,1]）。**已由 20×20 更新为 36×36** |
| 尺寸掩码通道 | 36×36×1，标记有效像素（原始 ROI 不足 36×36 时填充区域置 0），避免填充值干扰 |
| 上下文环带 | **已内置于 36×36 输入**：外圈 8px 即背景环带，供 `bg_stats` 估计局部背景均值/标准差，是"相对暗判定"的基础 |
| 手工结构特征（可选） | 8 维（见 4.2）。**注意：消融表明训练充分后去掉它更好，推荐 `--no-handcrafted`** |

> 说明：候选 ROI 可由上游滑窗、帧差或显著性检测产生，本方案聚焦 ROI 级判别模型。

### 2.2 输出定义

| 输出 | 类型 | 定义 |
|---|---|---|
| `prob` | 二分类概率 ∈ [0,1] | **是否为无人机/飞机**（sigmoid 输出，单头） |
| `confidence` | 标量 | 二分类下即等于 `prob`（正类概率） |

> 已移除原 `black_exist` + 3 分类 `class_probs` 的双头结构与两级级联。

### 2.3 两级级联结构（**已废弃**）
> 原设计"第一级黑色元素判定 + 第二级三分类"的两级级联**已移除**。
> 当前实现为**单头二分类**：骨干 + 单 sigmoid 头直接输出 `P(无人机)`（见 4.1）。
> 废弃原因：任务收敛为"是否为无人机"的二分类后，级联不再必要；单头端到端训练更直接，部署只需一个概率输出。

## 3. 黑色元素判定标准与阈值设定

### 3.1 判定原则：相对黑暗而非绝对黑暗
远距离无人机因逆光/机身吸光呈暗色，但其绝对亮度受天气、曝光影响大，因此采用**相对局部背景的对比度判定**。

### 3.2 像素级"暗像素"判定
对 ROI 内像素 \(p\)，满足以下条件即为暗像素：

$$Y(p) < T_{dark}, \quad T_{dark} = \max\left(\mu_{bg} - k \cdot \sigma_{bg},\; T_{abs}\right)$$

- \(\mu_{bg}, \sigma_{bg}\)：上下文环带（ROI 外 8 像素环）的均值与标准差；
- \(k\)：**初始取 2.5**，在验证集上按 FAR（虚警率）网格搜索确定，典型范围 2.0~3.5；
- \(T_{abs}\)：绝对亮度下限保护，**初始取 0.35×255 ≈ 90**，防止高亮背景下把"略暗的云"误判为黑元素；阴天场景下需通过自适应标定更新。

### 3.3 区域级"黑色元素存在"判定

> **统计区口径（2026-10-21 修订）**：以下占比/面积类判据的统计区是 **中心 20×20 目标区**（`core_region()`），
> 而非整个 36×36 画布；背景 μ_bg / σ_bg 仍取自外圈 8px 环带。二者必须分离，
> 否则占比阈值会随画布尺寸放大而失效。

暗像素需构成**紧凑连通实体**而非弥散过渡带，同时满足（数值为代码当前值，已在合成集标定）：

| 条件 | 阈值（当前值） | 说明 |
|---|---|---|
| 暗像素占比 | ≥ 2%（≥8 像素 / 400） | 最小目标仅 4~8 像素，10% 的原设定不适用 |
| 最大暗连通域面积 | ≥ 6 像素 | 排除椒盐噪声 |
| 紧凑度 \(4\pi A / P^2\) | ≥ 0.35 | 团状 vs 条带状的第一道粗筛（边缘通常 < 0.3） |
| 最小闭合对比度 | \((\mu_{bg} - \bar{Y}_{blob}) / \mu_{bg} \geq 0.12\) | 模糊退化后目标芯对比度实测约 0.1~0.4 |

**合成集实测（正样本 300 例）单项通过率**：暗像素占比 62.0%、连通域面积 61.7%、紧凑度 61.3%、闭合对比度 91.0%，
**四项同时通过 54.7%** —— 即规则法对真无人机约有一半漏检，这正是"传统算法不可用"的量化证据。

> 以上阈值仅作为**传统判据的初始值与数据标注基准**。部署时由 `DroneNet` 直接输出概率（见 4.1），上述规则用于：
> (a) 自动生成弱标签；(b) 作为规则基线对照组（`scripts/baseline_eval.py`）；(c) 可解释性审计与安全兜底。

### 3.4 三类目标的判别依据（第二级核心特征）

| 判别维度 | 无人机小目标 | 天空边缘 | 云层边缘 |
|---|---|---|---|
| 暗像素几何形态 | 紧凑团状，近似各向同性 | 条带/线状，沿边缘延伸 | 弥散片状，边界模糊 |
| 梯度分布 | 四周均有指向斑心的梯度（闭合对比） | 梯度方向单一（垂直于边缘） | 梯度弱且方向杂乱 |
| 对比度 | 高（暗斑 vs 亮天） | 中等（两侧亮度差） | 低且缓慢过渡 |
| 时域特性（可选） | 连续帧间位置连续移动、亮度稳定 | 静止或随相机整体运动 | 形变缓慢、亮度漂移 |

梯度方向对称性可量化为：以暗斑质心为原点，统计梯度方向直方图的**对向能量比**（0°~180° 成对方向的能量均衡度），理论上无人机 ≈ 1、边缘 ≪ 1。

**合成集实测分布（2026-10-21）**：无人机 `sym` 中位 **0.304**（p90 0.648），天空边缘中位 **0.000**（p90 0.437），云层/背景 ≈ 0.000（其暗像素为空，按定义取 0）。
可见该特征区分度很好，但**绝对量级远低于理论值 1**（小目标仅十余个像素，方向直方图极稀疏），
故规则判据的团状门限取 **`sym ≥ 0.15`** 而非 0.4——后者会误杀约 60% 的真目标。

## 4. 模型结构设计

### 4.1 总体架构（轻量双头 CNN）

```
输入: 36×36×2 (Y + mask)   # 外圈 8px 为背景环带
  │
  ├─ Conv 3×3, 16 → BN → ReLU           (36→34)
  ├─ Conv 3×3, 32 → BN → ReLU           (34→32)
  ├─ SE Block (通道注意力)
  ├─ Conv 3×3, 64 → BN → ReLU           (32→30)
  ├─ SE Block
  ├─ Conv 3×3, 64 → BN → ReLU           (30→28)
  ├─ GlobalAvgPool + GlobalMaxPool 拼接 (128)
  │
  ├─ [可选] 拼接手工结构特征 (8 维，见 4.2) → 136
  │
  └─ FC 96 → ReLU → FC 1 → sigmoid → P(无人机)     # 单头二分类
```

- 参数量 **76,473（实测）**；桌面 CPU（ONNX Runtime）实测：batch=1 约 0.45 ms/ROI、batch=30 **2.81 ms/批（≈94 μs/ROI，约 10,700 ROI/s）**；带手工特征时预处理另需 0.124 ms/ROI，**端到端 0.252 ms/ROI**；嵌入式场景配合 NPU 可进一步加速；
- 不使用池化降采样，用卷积保留微小目标的空间信息；
- SE 注意力代价极小，可增强对暗斑通道响应的筛选；
- **纯 CNN 版（无手工特征）为单输入 tensor→tensor 图，可整块上 NPU/RKNN**，部署侧无需 OpenCV 预处理。

### 4.2 手工结构特征分支（8 维，与 CNN 特征融合）
1. 暗像素占比；2. 最大暗连通域面积；3. 紧凑度；4. 闭合对比度；
5. 梯度方向对向能量比；6. 暗斑质心偏移；7. ROI 边缘暗像素占比（边缘类目标暗像素常触及 ROI 边界，无人机通常居中不触边）；8. 暗斑长短轴比（PCA 主轴比）。

> 手工特征与 CNN 融合兼顾可解释性与小样本稳定性；但**消融实验已给出明确结论（2026-10-20）**：
>
> 训练充分后（10 epochs × 4800 样本，合成数据），**去掉手工特征的纯 CNN 反而更优**：
> AUC **0.945** vs 0.928、AP 0.919 vs 0.892、F1 **0.821** vs 0.772、recall@FAR=1e-3 0.647 vs 0.597。
>
> 原因是手工特征属**归纳先验**：小数据、少训练步时帮模型快速收敛，但它是人工设计的**有损压缩**（连通域→"紧凑度"标量、梯度分布→"对称度"标量），训练充分后 CNN 自学到的高维表示信息量更大。**故推荐默认使用纯 CNN（`--no-handcrafted`）**，手工特征仅在实拍数据极少且训练不充分时作为可选先验。
>
> ⚠️ 3 epochs 的欠训练消融曾得出相反结论（0.647 vs 0.426），那是"收敛速度"差异而非最终上限，做消融务必训练充分。

### 4.3 损失函数

$$L = L_{BinaryFocal}(is\_drone)$$

- 二分类用 **Binary Focal Loss**（γ=2），缓解正样本（无人机）稀少问题；
- 目标为 `is_drone`（1=无人机，0=其他），直接对 sigmoid 前的 logit 计算；
- 优化器 AdamW（lr 3e-4，weight_decay 1e-4）+ CosineAnnealing 调度；**微调时建议 lr 降到 1e-4~5e-5**。

## 5. 样本数据构建

### 5.1 数据来源与配比

| 类别 | 来源 | 训练集占比建议 |
|---|---|---|
| 无人机小目标 | 实地采集（多机型、多距离 1~5 km、多天气）+ 数据合成 | 25% |
| 天空边缘 | 地平线、建筑物/山脊轮廓、天线塔架边缘等 | 30% |
| 云层边缘 | 各类云（积云/层云/卷云）边缘区域 | 30% |
| 纯背景（无黑元素） | 均匀天空、云内部 | 15% |

### 5.2 实地采集规范
- 无人机悬停/航线飞行，距离梯度采样（每 250 m 一档），覆盖 **2×2 到 18×18** 像素的目标尺度（与合成管线一致，含极小目标）；
- 不同时段（顺光/逆光/顶光）、天气（晴/阴/薄雾）、背景（纯天/云背景/地平线）；
- 用长焦 + 高分辨率相机录制，转灰度 Y 通道后标注。

### 5.3 数据合成管线（解决正样本稀缺）
1. **目标素材**：无人机 3D 模型多角度渲染或实拍抠图，获得高分辨率剪影；
2. **距离退化模拟**：
   - 缩放到 2×2 ~ 18×18 像素（双三次 + 随机亚像素偏移，模拟目标落在像素网格不同相位）；
   - 大气 PSF 模糊：高斯核 σ ∈ [0.3, 0.9]，**并实现 size-aware blur**——模糊核上限随目标边长缩放（2×2→σ≤0.4，4×4→σ≤0.8，≥5×5→σ≤0.9），避免极小目标被模糊链抹掉而不可学；
   - 大气透过率衰减：对比度 ×τ，τ ∈ [0.6, 1.0]；
   - 传感器噪声：高斯噪声 σ ∈ [1, 6]/255 + 少量椒盐噪声（概率 ≤ 2%）；
3. **背景贴合**：从真实天空/云层图像库随机取 36×36 背景块，将退化后目标以随机亮度系数
   **α ∈ [0.25, 0.65] × τ**（相对背景的变暗深度）融合；其中**目标 < 5px 时 α 下限提到 0.45**，
   与 size-aware blur 配合，保证极小目标的核心仍有足够对比度可供学习；
4. **合成负样本**：对天空/云边缘图像施加同样的模糊、下采样退化——**必须与正样本退化管线一致**，否则模型会学到"模糊程度"捷径而非目标本质。

### 5.4 数据增强
- 亮度缩放 ×[0.7, 1.3]、gamma ∈ [0.8, 1.25]；
- 平移 ±3 像素、旋转 ±15°、水平翻转；
- 随机模糊/噪声（与合成管线参数域一致）；
- **禁止**：颜色抖动（Y 单通道）、过大旋转（边缘方向是判别特征）。

### 5.5 数据集划分（防泄漏）
- **按视频序列/采集场次划分** train/val/test = 7:1.5:1.5，同一场景的帧不得跨集合；
- 测试集需包含**未见过的场地、天气、机型**，检验泛化；
- 建议规模：每类 ≥ 20,000 ROI（合成+实拍混合，实拍占比 ≥ 15%，并保证测试集 100% 实拍）。

### 5.6 标注规范
- 暗元素标注以 3.2/3.3 节规则自动生成弱标签 → 人工复核修正；
- 三分类标注由采集时记录的 ground truth（无人机 GPS/已知目标位）与人工确认完成；
- 边界模糊样本（label 置信度低）单独标记，训练时用 label smoothing 0.05。

## 6. 性能评估指标与验证方法

### 6.1 指标体系

**(A) 黑色元素判定（规则基线 / 安全兜底，非模型级联）**

> 二分类改造后，黑色元素判定不再是模型的第一级（级联已废弃），
> 仅作为规则基线对照组与可解释性审计使用（`scripts/baseline_eval.py`）。

| 指标 | 说明 | 目标参考值 |
|---|---|---|
| Precision / Recall / F1 | 存在性判断 | Recall ≥ 98%（宁多勿漏） |
| FAR（虚警率） | 每 ROI / 每帧误报数 | 每帧 ≤ 0.5 个 |

**(B) 二分类判别（当前核心指标）**

| 指标 | 说明 |
|---|---|
| Precision / Recall / F1 | 默认阈值 0.5 下的判别性能 |
| FAR（每 ROI 虚警率） | 部署虚警约束的直接依据 |
| AUC / AP | 阈值无关的整体判别能力 |
| **固定 FAR 下召回率** | 如 FAR=10⁻³ / 10⁻⁴/ROI 时的召回率（最贴近业务，用于选部署阈值） |
| 误报 / 漏检样本的置信度分布 | 用于标定置信度阈值与失败分析 |

**(C) 系统级指标（ROI 级 → 帧级 → 跟踪级）**
- 帧级：每帧虚警数（FFA）、帧级漏检率；
- 跟踪级（如有下游跟踪）：连续 N 帧确认后的轨迹级 FAR 与 MTBF（平均无虚警时间）；
- 效率：单 ROI 推理延迟、整机吞吐（ROI/秒）、模型体积与参数量。

### 6.2 验证方法

1. **留出测试集验证**：按 5.5 节独立测试集评估，报告全部 6.1 指标；
2. **分层交叉验证**：按场景（天气×时段×场地）分层做 K=5 交叉验证，报告均值 ± 标准差；
3. **阈值扫描与工作点选择**：对综合置信度做阈值扫描，绘制 PR/ROC 曲线，按业务约束（如每帧 ≤ 0.5 虚警）确定工作点；
4. **对比基线**（证明"传统算法无法区分"的改进）：
   - 基线 1：灰度阈值 + 形态学（3.3 节规则，`scripts/baseline_eval.py`）；
   - 基线 2：手工特征 + SVM/AdaBoost；
   - 基线 3：本方案（`DroneNet` 二分类 CNN）；
   - 同测试集对比 F1 / AUC / FAR 与固定 FAR 下召回率；
   - **合成集实测对照（2026-10-21，1500 样本/类 × 15 epochs）**：

     | 方法 | F1 | AUC | FAR/ROI |
     |---|---|---|---|
     | 规则基线 | 0.019 | 0.708 | 0.020 |
     | DroneNet | **0.876** | **0.958** | **0.0089** |

     （须以 100% 实拍测试集复核，合成集仅证明管线可用与量级差异）
5. **统计显著性检验**：Bootstrap 重采样 1000 次计算指标 95% 置信区间；McNemar 检验对比本方案与基线的逐样本判定差异；
6. **鲁棒性测试**：对测试集分别注入额外噪声/模糊/亮度漂移，绘制性能-退化程度曲线；
7. **消融实验**（验证设计有效性）：
   - 去掉手工结构特征分支；
   - 去掉上下文环带（无背景对比信息）；
   - **纯 CNN（去掉手工特征）vs 保留手工特征**（已完成：训练充分后纯 CNN 更优，见 4.2 与顶部状态说明）；
   - 合成数据占比 0% / 50% / 85% 的影响；
8. **失败案例分析**：固定抽取每类错误 Top-100 样本人工归因（过曝/极端距离/边缘恰好闭合等），反馈迭代 5.3 节合成管线参数域。

### 6.3 验收标准建议（二分类口径）
- 无人机 Recall ≥ 95%（在业务允许的 FAR 工作点下，如 FAR=10⁻³~10⁻⁴/ROI）；
- 每 ROI 虚警率 FAR 满足业务约束（如 ≤10⁻⁴）；
- 实拍验证集 AUC ≥ 0.90；
- 交叉场景（未见场地/天气）性能下降 ≤ 5 个百分点；
- 部署时延满足预算：**按每 ROI 口径**（如 ≤ 2 ms/ROI），用 `scripts/benchmark_onnx.py` 在目标板实测。
  ⚠️ 注意该脚本打印的"批总耗时"需除以批大小才能与 per-ROI 预算比较（2026-10-21 已修正该口径）。
