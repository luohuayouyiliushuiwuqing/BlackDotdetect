# 远距离无人机黑色小目标检测模型设计方案

## 1. 任务定义与问题分析

### 1.1 任务描述
在天空背景下，对尺寸小于 20×20 像素的 Y 分量（亮度）图像区域进行判别：
1. 区域内是否存在"黑色元素"（二值判断）；
2. 若存在，进一步区分该黑色元素属于哪一类目标：**无人机小目标 / 天空边缘 / 云层边缘**（三分类）。

### 1.2 难点分析（为什么传统算法失效）
- **信息极度稀疏**：20×20 区域内有效目标像素可能仅 5~50 个，传统形态学+阈值方法依赖的连通域形状特征几乎不可用。
- **三类目标在低分辨率下亮度分布高度重叠**：远距离无人机呈"暗色斑点"，而天空/云层边缘在高斯模糊和下采样后同样会产生局部暗像素带，纯阈值法无法区分"边缘过渡的暗"与"实体目标的暗"。
- **边缘与斑点的本质区别**：边缘暗像素呈**条带状、单侧渐变、沿边缘方向连续**；无人机目标呈**紧凑团状、四周均与亮背景形成闭合对比、各向梯度近似对称**。这一差异需要空间结构建模（CNN/手工结构特征），单像素阈值无法表达。

## 2. 模型输入输出定义

### 2.1 输入定义

| 项目 | 定义 |
|---|---|
| 主输入 | Y 分量 ROI 图像块，统一缩放/填充至 **20×20×1**（uint8 归一化到 [0,1]） |
| 尺寸掩码通道 | 20×20×1，标记有效像素（原始 ROI 不足 20×20 时填充区域置 0），避免填充值干扰 |
| 上下文环带（可选，推荐） | 以 ROI 为中心外扩 8 像素的 36×36 Y 分量块，用于估计局部背景亮度与对比度。若算力受限可裁剪为仅提供统计量 |
| 辅助统计特征（可选） | 局部背景均值 μ_bg、背景标准差 σ_bg、ROI 最小值/均值、ROI 与背景对比度 |

> 说明：候选 ROI 可由上游滑窗、帧差或显著性检测产生，本方案聚焦 ROI 级判别模型。

### 2.2 输出定义

| 输出 | 类型 | 定义 |
|---|---|---|
| `black_exist` | 二分类概率 ∈ [0,1] | 区域内是否存在黑色元素（第一级判断） |
| `class_probs` | 3 维概率向量 | P(无人机), P(天空边缘), P(云层边缘)，softmax 输出（第二级判断） |
| `confidence` | 标量 | 综合置信度 = `black_exist` × max(`class_probs`) |
| `center_offset`（可选） | (dx, dy) | 暗斑质心相对 ROI 中心的偏移，用于上游跟踪模块 |

### 2.3 两级级联结构
- **第一级：黑色元素判定头** —— 快速过滤纯亮区域（纯天空/纯云内部），降低第二级计算量；
- **第二级：三分类头** —— 仅在第一级判"存在"时激活，区分无人机/天空边缘/云层边缘。

两级可共享骨干网络，以两个输出头实现（multi-task），共享特征可互相促进。

## 3. 黑色元素判定标准与阈值设定

### 3.1 判定原则：相对黑暗而非绝对黑暗
远距离无人机因逆光/机身吸光呈暗色，但其绝对亮度受天气、曝光影响大，因此采用**相对局部背景的对比度判定**。

### 3.2 像素级"暗像素"判定
对 ROI 内像素 \(p\)，满足以下条件即为暗像素：

$$Y(p) < T_{dark}, \quad T_{dark} = \max\left(\mu_{bg} - k \cdot \sigma_{bg},\; T_{abs}\right)$$

- \(\mu_{bg}, \sigma_{bg}\)：上下文环带（ROI 外 8 像素环）的均值与标准差；
- \(k\)：**初始取 2.5**，在验证集上按 FAR（虚警率）网格搜索确定，典型范围 2.0~3.5；
- \(T_{abs}\)：绝对亮度下限保护，**初始取 0.35×255 ≈ 90**，防止高亮背景下把"略暗的云"误判为黑元素；阴天场景下需通过自适应标定更新。

### 3.3 区域级"黑色元素存在"判定
暗像素需构成**紧凑连通实体**而非弥散过渡带，同时满足：

| 条件 | 阈值（初始值） | 说明 |
|---|---|---|
| 暗像素占比 | ≥ 10%（≥40 像素 / 400） | 排除零星噪声点 |
| 最大暗连通域面积 | ≥ 6 像素 | 排除椒盐噪声 |
| 紧凑度 \(4\pi A / P^2\) | ≥ 0.35 | 团状 vs 条带状的第一道粗筛（边缘通常 < 0.3） |
| 最小闭合对比度 | \((\mu_{bg} - \bar{Y}_{blob}) / \mu_{bg} \geq 0.25\) | 暗斑相对背景的相对深度 |

> 以上阈值仅作为**第一级传统判据的初始值与数据标注基准**。最终部署时，黑色元素判定由学习到的判定头给出，上述规则用于：(a) 自动生成弱标签；(b) 作为模型失效时的安全兜底；(c) 可解释性审计。

### 3.4 三类目标的判别依据（第二级核心特征）

| 判别维度 | 无人机小目标 | 天空边缘 | 云层边缘 |
|---|---|---|---|
| 暗像素几何形态 | 紧凑团状，近似各向同性 | 条带/线状，沿边缘延伸 | 弥散片状，边界模糊 |
| 梯度分布 | 四周均有指向斑心的梯度（闭合对比） | 梯度方向单一（垂直于边缘） | 梯度弱且方向杂乱 |
| 对比度 | 高（暗斑 vs 亮天） | 中等（两侧亮度差） | 低且缓慢过渡 |
| 时域特性（可选） | 连续帧间位置连续移动、亮度稳定 | 静止或随相机整体运动 | 形变缓慢、亮度漂移 |

梯度方向对称性可量化为：以暗斑质心为原点，统计梯度方向直方图的**对向能量比**（0°~180° 成对方向的能量均衡度），无人机 ≈ 1，边缘 ≪ 1。

## 4. 模型结构设计

### 4.1 总体架构（轻量双头 CNN）

```
输入: 20×20×2 (Y + mask)   [可选 36×36 上下文分支]
  │
  ├─ Conv 3×3, 16 → BN → ReLU          (20×20×16)
  ├─ Conv 3×3, 32, stride 1 → BN → ReLU (18×18×32)
  ├─ SE Block (通道注意力)
  ├─ Conv 3×3, 64 → BN → ReLU           (16×16×64)
  ├─ SE Block
  ├─ Conv 3×3, 64 → BN → ReLU           (14×14×64)
  ├─ GlobalAvgPool + GlobalMaxPool 拼接 (128)
  │
  ├─ 拼接手工结构特征 (8 维，见 4.2) → FC 96 → ReLU
  │
  ├─ 头1: FC 1 → sigmoid   → black_exist
  └─ 头2: FC 3 → softmax   → class_probs
```

- 参数量约 **6~8 万**，单 ROI 推理 < 0.1 ms（CPU），适合嵌入式机载部署；
- 不使用池化降采样，用 stride/卷积保留微小目标的空间信息；
- SE 注意力代价极小，可增强对暗斑通道响应的筛选。

### 4.2 手工结构特征分支（8 维，与 CNN 特征融合）
1. 暗像素占比；2. 最大暗连通域面积；3. 紧凑度；4. 闭合对比度；
5. 梯度方向对向能量比；6. 暗斑质心偏移；7. ROI 边缘暗像素占比（边缘类目标暗像素常触及 ROI 边界，无人机通常居中不触边）；8. 暗斑长短轴比（PCA 主轴比）。

> 手工特征与 CNN 融合兼顾可解释性与小样本稳定性；若数据充足可通过消融实验决定是否保留。

### 4.3 损失函数

$$L = \lambda_1 L_{BCE}(black\_exist) + \lambda_2 L_{Focal}(class)$$

- 三分类用 **Focal Loss**（γ=2），缓解无人机正样本稀少问题；
- 对纯背景样本（无黑色元素）只回传第一级损失（mask 掉第二级）；
- λ₁=1.0, λ₂=2.0（正样本稀少时上调 λ₂）。

## 5. 样本数据构建

### 5.1 数据来源与配比

| 类别 | 来源 | 训练集占比建议 |
|---|---|---|
| 无人机小目标 | 实地采集（多机型、多距离 1~5 km、多天气）+ 数据合成 | 25% |
| 天空边缘 | 地平线、建筑物/山脊轮廓、天线塔架边缘等 | 30% |
| 云层边缘 | 各类云（积云/层云/卷云）边缘区域 | 30% |
| 纯背景（无黑元素） | 均匀天空、云内部 | 15% |

### 5.2 实地采集规范
- 无人机悬停/航线飞行，距离梯度采样（每 250 m 一档），覆盖 4×4 到 20×20 像素的目标尺度；
- 不同时段（顺光/逆光/顶光）、天气（晴/阴/薄雾）、背景（纯天/云背景/地平线）；
- 用长焦 + 高分辨率相机录制，转灰度 Y 通道后标注。

### 5.3 数据合成管线（解决正样本稀缺）
1. **目标素材**：无人机 3D 模型多角度渲染或实拍抠图，获得高分辨率剪影；
2. **距离退化模拟**：
   - 缩放到 2×2 ~ 18×18 像素（双三次 + 随机亚像素偏移，模拟目标落在像素网格不同相位）；
   - 大气 PSF 模糊：高斯核 σ ∈ [0.4, 1.5]；
   - 大气透过率衰减：对比度 ×τ，τ ∈ [0.5, 1.0]；
   - 传感器噪声：高斯噪声 σ ∈ [1, 6]/255 + 少量椒盐噪声；
3. **背景贴合**：从真实天空/云层图像库随机取 36×36 背景块，将退化后目标以随机亮度系数 α ∈ [0.1, 0.6]（相对背景变暗的程度）融合；
4. **合成负样本**：对天空/云边缘图像施加同样的模糊、下采样退化——**必须与正样本退化管线一致**，否则模型会学到"模糊程度"捷径而非目标本质。

### 5.4 数据增强
- 亮度缩放 ×[0.7, 1.3]、gamma ∈ [0.8, 1.25]；
- 平移 ±3 像素、旋转 ±15°、水平翻转；
- 随机模糊/噪声（与合成管线参数域一致）；
- **禁止**：颜色抖动（Y 单通道）、过大旋转（边缘方向是判别特征）。

### 5.5 数据集划分（防泄漏）
- **按视频序列/采集场次划分** train/val/test = 7:1.5:1.5，同一场景的帧不得跨集合；
- 测试集需包含**未见过的场地、天气、机型**，检验泛化；
- 建议规模：每类 ≥ 20,000 ROI（合成+实拍混合，实拍占比 ≥ 15%，并保证测试集 100% 实拍）。

### 5.6 标注规范
- 暗元素标注以 3.2/3.3 节规则自动生成弱标签 → 人工复核修正；
- 三分类标注由采集时记录的 ground truth（无人机 GPS/已知目标位）与人工确认完成；
- 边界模糊样本（label 置信度低）单独标记，训练时用 label smoothing 0.05。

## 6. 性能评估指标与验证方法

### 6.1 指标体系

**(A) 黑色元素判定（第一级，二分类）**

| 指标 | 说明 | 目标参考值 |
|---|---|---|
| Precision / Recall / F1 | 存在性判断 | Recall ≥ 98%（宁多勿漏） |
| FAR（虚警率） | 每百万 ROI 误报数，或每帧误报数 | 每帧 ≤ 0.5 个 |

**(B) 三分类（第二级，核心指标）**

| 指标 | 说明 |
|---|---|
| 3×3 混淆矩阵 | 重点关注"无人机 → 边缘"漏检与"边缘 → 无人机"虚警两格 |
| 无人机类 Precision / Recall / F1 | 小目标检测核心业务指标 |
| Macro-F1 | 三类均衡性能 |
| 无人机 vs (天空边缘+云层边缘) 的 ROC / AUC | 阈值无关性能 |
| **PR 曲线 + 固定 FAR 下召回率** | 如 FAR=10⁻⁴/ROI 时的无人机召回率（最贴近业务） |
| 每类错误样本的置信度分布 | 用于标定置信度阈值 |

**(C) 系统级指标（ROI 级 → 帧级 → 跟踪级）**
- 帧级：每帧虚警数（FFA）、帧级漏检率；
- 跟踪级（如有下游跟踪）：连续 N 帧确认后的轨迹级 FAR 与 MTBF（平均无虚警时间）；
- 效率：单 ROI 推理延迟、整机吞吐（ROI/秒）、模型体积与参数量。

### 6.2 验证方法

1. **留出测试集验证**：按 5.5 节独立测试集评估，报告全部 6.1 指标；
2. **分层交叉验证**：按场景（天气×时段×场地）分层做 K=5 交叉验证，报告均值 ± 标准差；
3. **阈值扫描与工作点选择**：对综合置信度做阈值扫描，绘制 PR/ROC 曲线，按业务约束（如每帧 ≤ 0.5 虚警）确定工作点；
4. **对比基线**（证明"传统算法无法区分"的改进）：
   - 基线 1：灰度阈值 + 形态学（3.3 节规则）；
   - 基线 2：手工特征 + SVM/AdaBoost；
   - 基线 3：本方案（CNN 双头）；
   - 同测试集对比三类混淆矩阵与固定 FAR 下召回率；
5. **统计显著性检验**：Bootstrap 重采样 1000 次计算指标 95% 置信区间；McNemar 检验对比本方案与基线的逐样本判定差异；
6. **鲁棒性测试**：对测试集分别注入额外噪声/模糊/亮度漂移，绘制性能-退化程度曲线；
7. **消融实验**（验证设计有效性）：
   - 去掉手工结构特征分支；
   - 去掉上下文环带（无背景对比信息）；
   - 单头（仅三分类，无第一级）vs 双头；
   - 合成数据占比 0% / 50% / 85% 的影响；
8. **失败案例分析**：固定抽取每类错误 Top-100 样本人工归因（过曝/极端距离/边缘恰好闭合等），反馈迭代 5.3 节合成管线参数域。

### 6.3 验收标准建议
- 无人机类 Recall ≥ 95%（FAR = 10⁻⁴/ROI 工作点下）；
- "天空/云层边缘 → 无人机"单向虚警率 ≤ 0.1%；
- Macro-F1 ≥ 0.90；
- 交叉场景（未见场地/天气）性能下降 ≤ 5 个百分点。
